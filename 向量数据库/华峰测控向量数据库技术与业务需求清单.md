# 华峰测控向量数据库技术与业务需求清单

## 一、业务背景

### 数据容量

文档总量约 9 万–13.5 万篇，文本 chunk 约 19 万–28 万条；考虑图片、PDF 及后续增长，容量按 **50 万条** 规划。详细估算过程见附录 A。

嵌入模型使用 Qwen3-VL-Embedding-8B，输出维度为默认的 4096 维（模型支持 64–4096 自定义维度，当前未调整）。单条向量按 float32 计算占 16 KB，50 万条原始向量约 **8 GB**，不含索引、原文和元数据。

### 用户规模

总用户约 100 人，峰值同时在线不超过 5 人。

## 二、需求清单

### 业务需求

| 需求                 | 类型    | 详细说明                                                                                                                      |     |
| ------------------ | ----- | ------------------------------------------------------------------------------------------------------------------------- | --- |
| **混合检索**           | 检索能力  | 除稠密向量（Dense Vector）相似度搜索外，支持基于关键词的全文检索（如 BM25，常以稀疏向量 Sparse Vector 形式实现），提升行业术语、型号编码等精确词的召回效果。支持多路召回结果的融合与重排（如 RRF、加权融合）。 |     |
| **元数据管理**          | 检索能力  | 支持为向量片段附加元数据（Metadata）。检索时支持基于元数据过滤（如按产品、版本过滤），以缩小搜索范围、提高准确率。                                                             |     |
| **分组检索**           | 检索能力  | 支持按字段分组检索（Grouping Search），避免多个版本内容高度重复时 top-k 结果被同一段落的不同版本占满。                                                            |     |
| **数据增量更新**         | 数据管理  | 支持数据的增量写入、更新（Upsert）和删除，变更完成后可被立即检索，无需手动重建索引。                                                                             |     |
| **读写并发稳定性**        | 数据管理  | 查询/检索请求不被写操作阻塞，不出现连接超时，同时查询延迟无明显增加。                                                                                       |     |
| **数据持久化**          | 数据管理  | 具备稳定可靠的数据落盘和状态持久化能力，确保服务重启或意外中断后数据不丢失。                                                                                    |     |
| **数据隔离**           | 数据管理  | 支持创建多个相互隔离的数据库。支持基于用户和角色的权限控制（RBAC），权限可细化到数据库或集合级别。                                                                       |     |

### 技术需求

| 需求                 | 类型  | 说明                                                                                        |     |
| ------------------ | --- | ----------------------------------------------------------------------------------------- | --- |
| **支持 C/S 架构**      | 部署  | 能作为独立服务运行，通过 HTTP/REST 或 gRPC 协议对外提供服务。                                                   |     |
| **私有化部署**          | 部署  | 在无外网连接的企业内部环境中独立部署，不依赖任何外部云服务，确保企业数据的安全。                                                  |     |
| **容器化部署**          | 部署  | 支持 Docker 及 Kubernetes 部署。                                                                |     |
| **日常健康监控**         | 运维  | 提供标准的健康检查接口。原生支持或易于集成监控组件，对 CPU/内存占用、QPS、检索延迟、索引构建进度等关键指标进行监测。                            |     |
| **接口与 Agent 工具集成** | 集成  | 提供 Python SDK 及 REST/gRPC 接口，便于 MCP Server 直接调用并包装为标准工具（Tools）。具备官方或社区维护的 MCP Server 者优先。 |     |

#### 容量规划

- 当前文本 chunk 合计：约 19 万–28 万条。
- 规划容量：**50 万条**（预留图片、PDF 及后续增长）。
- 嵌入模型：Qwen3-VL-Embedding-8B，默认输出维度 4096。
- 单条向量（float32）：16 KB；50 万条原始向量约 8 GB（不含索引、原文和元数据）。
