拿到机器看什么，针对向量数据库，优先看三样：**系统内存（RAM）大小、磁盘空间与类型（必须是SSD，机械硬盘跑不动向量检索）、CPU核心数**

**linux 系统命令**

```bash
# 查看内存大小
free -h

# 磁盘剩余空间
df -h

# 某目录具体大小
du -sh /path/to/dir

# CPU核心数
lscpu 或 nproc

```

**Docker 查看资源**
```
docker stats
```
实时动态显示所有运行中容器的 **CPU使用率、当前内存占用 / 内存上限、网络I/O和磁盘读写**。

| **查看目标**    | **说明**                          |
| ----------- | ------------------------------- |
| **内存大小**    | 重点看 `available` 列，代表当前真正还能用的内存。 |
| **磁盘剩余空间**  | 查看各挂载点的磁盘总容量及使用率。               |
| **某目录具体大小** | 查看数据库挂载目录实际占用了多少磁盘。             |
| **CPU 核心数** | 查看 CPU 物理核与逻辑线程数（决定并发上限）。       |
